# Gute erste Aufgaben

[English](ISSUES_GOOD_FIRST.md) · [Română](ISSUES_GOOD_FIRST.ro.md) · [Français](ISSUES_GOOD_FIRST.fr.md) · [Italiano](ISSUES_GOOD_FIRST.it.md) · [Español](ISSUES_GOOD_FIRST.es.md) · [Português](ISSUES_GOOD_FIRST.pt.md) · **Deutsch** · [Magyar](ISSUES_GOOD_FIRST.hu.md)

- [ ] Die Prüf-API (Eingaben, Ausgaben, Statusstufen) in docs/check-api.md spezifizieren
- [ ] Eine vollständige EXIF-Prüfung implementieren (GPS, Kamera, Software, Zeitstempel)
- [ ] Eine Prüfung des C2PA-Manifests hinzufügen (offline, nur lesend)
- [ ] Eine Prüfung auf tote Links und Weiterleitungsketten für eine URL-Liste hinzufügen
- [ ] Eine Domainprüfung hinzufügen: DNS/TLS-Zusammenfassung ohne WHOIS über öffentliches DoH
- [ ] Eine Error-Level-Analyse (ELA) für JPEG-Bilder hinzufügen
- [ ] Eine Hilfe „im Internet Archive speichern“ hinzufügen (vom Nutzer ausgelöst, klar gekennzeichnet)
- [ ] Einen druckbaren Prüfbericht als PDF/Markdown erzeugen
- [ ] Eine Prüfung mit Video-Keyframe-Extraktion hinzufügen (Canvas, offline)
- [ ] Einen Ethikhinweis schreiben: was diese Werkzeuge nicht beweisen können

Lege sie alle auf GitHub mit `scripts/create_issues.sh` an (benötigt die `gh`-CLI).
