- [ ] Especificar la API de comprobaciones (entradas, salidas, niveles de estado) en docs/check-api.md
- [ ] Implementar una comprobación EXIF completa (GPS, cámara, software, marcas de tiempo)
- [ ] Añadir una comprobación del manifiesto C2PA (sin conexión, solo lectura)
- [ ] Añadir una comprobación de enlaces rotos y cadenas de redirecciones para una lista de URL
- [ ] Añadir una comprobación de dominio: resumen DNS/TLS sin WHOIS, mediante DoH público
- [ ] Añadir una comprobación por análisis de nivel de error (ELA) para imágenes JPEG
- [ ] Añadir una ayuda «guardar en Internet Archive» (iniciada por la persona usuaria, claramente etiquetada)
- [ ] Producir un informe de verificación imprimible en PDF/Markdown
- [ ] Añadir una comprobación con extracción de fotogramas clave de vídeo (canvas, sin conexión)
- [ ] Escribir una nota ética: lo que estas herramientas no pueden demostrar

Créalas todas en GitHub con `scripts/create_issues.sh` (requiere la CLI `gh`).
